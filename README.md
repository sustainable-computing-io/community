# Kepler Community

Start here to learn how the [sustainable-computing-io](https://github.com/sustainable-computing-io)
community works, how to get involved, and how to grow as a contributor.

Kepler is a [CNCF](https://www.cncf.io/projects/kepler/) Sandbox project.

## Projects

| Repository | Description |
|------------|-------------|
| [`kepler`](https://github.com/sustainable-computing-io/kepler) | Prometheus exporter that measures and attributes power to containers, pods, and nodes. Includes the Helm chart. |
| [`kepler-operator`](https://github.com/sustainable-computing-io/kepler-operator) | Kubernetes operator that deploys and manages Kepler |
| [`kepler-doc`](https://github.com/sustainable-computing-io/kepler-doc) | Source for [sustainable-computing.io](https://sustainable-computing.io/) |
| [`kepler-action`](https://github.com/sustainable-computing-io/kepler-action) | GitHub Action for Kepler CI |
| [`local-dev-cluster`](https://github.com/sustainable-computing-io/local-dev-cluster) | Local Kubernetes cluster for Kepler development |

## Get Involved

- **Talk to us:** [`#kepler-project`](https://cloud-native.slack.com/archives/C05QK3KN3HT) on [CNCF Slack](https://slack.cncf.io/)
- **Join a meeting:** see [MEETINGS.md](MEETINGS.md)
- **Try Kepler:** follow the [installation guide](https://sustainable-computing.io/kepler/installation/guide/)
- **Pick up work:** browse [good first issues](https://github.com/sustainable-computing-io/kepler/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22)
  or the [project board](https://github.com/orgs/sustainable-computing-io/projects/9/views/2),
  and comment on an issue before you start
- **Contribute:** read the [contributing guide](https://github.com/sustainable-computing-io/kepler/blob/main/CONTRIBUTING.md)
- **Tell us you use Kepler:** add your organization to [ADOPTERS.md](https://github.com/sustainable-computing-io/kepler/blob/main/ADOPTERS.md)

Contributions need not be code. Docs, testing, issue triage, answering questions,
talks, and blog posts all count.

## Grow as a Contributor

| Role | How to get there |
|------|------------------|
| Contributor | Open issues and PRs, review, answer questions, or help at meetings |
| Reviewer | Get nominated for one or more `OWNERS` files. See [Reviewer](https://github.com/sustainable-computing-io/kepler/blob/main/GOVERNANCE.md#reviewer). |
| Maintainer | Get nominated and approved by three maintainers. See [Leadership Election](https://github.com/sustainable-computing-io/kepler/blob/main/GOVERNANCE.md#leadership-election). |
